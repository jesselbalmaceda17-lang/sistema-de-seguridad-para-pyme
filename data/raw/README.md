# Datos originales

En este espacio de trabajo hay copias locales de
`UNSW_NB15_training-set.csv` y `UNSW_NB15_testing-set.csv`. Están excluidas por
`.gitignore`, así que no aparecen en un checkout limpio ni forman parte
automáticamente de una entrega de código. Su presencia local y sus hashes se
registran en `delivery-manifest.json` como referencias locales, no como
autorización de redistribución.

Antes de incluir o redistribuir el conjunto, confirme y registre fuente exacta,
versión, licencia y condiciones de uso. Para demostraciones de Streamlit use
`data/processed/demo_20_registros.csv`, derivado del conjunto de entrenamiento;
no sirve para estimar generalización. Reserve el archivo `testing-set.csv` para
la evaluación oficial documentada.

No añadir capturas o registros identificables de empresas sin autorización y
controles de privacidad apropiados.
